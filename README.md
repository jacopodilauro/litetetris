# LITETRIS


| Light | Dark |
|:-:|:-:|
|![gif](/img/tetris_git.gif)|![img](/img/tetris_dark.gif) |

Simple Tetris game running on terminal.

## How to compile

```easy
gcc litetris-terminal.c
```

## Commands
| Action | Key |
|---|---|
| Move | `a or ←` , `d or →` , `s or ↓` |
| Rotate | `w or ↑` |
| Quit | `q or [ESC]` |
